# Solisys

Microsoft cloud, identity and security, from design to day-to-day run.

Solisys is the consultancy of Olivier Lumeau, Senior Azure and Microsoft 365 Architect and Security Engineer based in Belgium. These public repositories share practical labs, reusable modules and hands-on material behind the articles on the [Solisys blog](https://www.solisys.be/blog/).
